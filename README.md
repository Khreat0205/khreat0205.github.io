# Kyeonghun Jeong Personal Website

Source for [khreat0205.github.io](https://khreat0205.github.io), built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme.

## Local Preview

```bash
docker compose up
```

Then open the local URL printed by Docker, usually `http://localhost:8081`.

## Main Content Files

- `_pages/about.md`: homepage biography
- `_pages/research.md`: research narrative
- `_bibliography/papers.bib`: publication metadata
- `_data/cv.yml`: CV data rendered by al-folio
- `assets/pdf/`: current CV PDF goes here after regeneration
- `_data/socials.yml`: email, GitHub, LinkedIn, and Google Scholar links
